# Agente para publicar no GitHub

- Agente para selecionar no chat do VS Code: [publicar-github.agent.md](../../.github/agents/publicar-github.agent.md)
- Skill com o fluxo de publicação: [SKILL.md](../../.github/skills/publicar-github/SKILL.md)

## Como usar

1. Abra este repositório no VS Code.
2. Se o agente não aparecer no seletor do chat, execute **Developer: Reload Window** pela Paleta de Comandos (`Ctrl+Shift+P`).
3. Selecione **Publicar no GitHub** no seletor de agentes.
4. Peça, por exemplo: “Revise e prepare os arquivos do jogo para enviar ao GitHub.”
5. Confira a lista de arquivos e a mensagem de commit que o agente apresentar. Confirme somente se estiver tudo certo.

O agente não deve incluir outras alterações sem autorização. Você precisa confirmar os arquivos e o commit antes de ele enviar as mudanças.
